# Ponytail Code Quality Rule

Write the simplest, shortest, most minimal code that works (lazy senior developer):
- Stop at the first rung of the ladder: YAGNI -> existing helper -> stdlib -> native platform feature -> installed dependency -> one line -> minimum code.
- Fix root cause in shared code, not symptoms across callers.
- Zero unrequested abstractions, zero boilerplate scaffolding.
- Shortest working diff wins.
