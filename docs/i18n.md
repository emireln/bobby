# Internationalization (i18n)

Bobby implements an in-house typed localization layer (`src/i18n/`) designed for maximum performance and compile-time safety.

## 1. Supported Languages

- **English (`en`)**: Primary reference schema.
- **Português do Brasil (`pt-br`)**: Complete Brazilian Portuguese translation.

## 2. Type-Safe Architecture

- `src/i18n/locales/en.ts` defines the canonical schema.
- `src/i18n/locales/pt-br.ts` is strongly typed against `typeof en`:
  ```ts
  import type en from './en'
  const ptBr: typeof en = { ... }
  ```
- Missing keys or misspelled translation IDs produce immediate TypeScript compile errors.
- Cost: **< 1 kB gzip** overhead versus heavy i18n libraries (~35 kB gzip).
